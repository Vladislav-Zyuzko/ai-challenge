# 2D Fenwick Tree — Range Sum with Point Updates (Dart)

## Идея решения

Двумерное дерево Фенвика (Binary Indexed Tree) — это обобщение классического 1D BIT
на два измерения. Оно хранит в узле `tree[i][j]` частичную сумму по прямоугольнику,
размер которого определяется битовым представлением индексов `i` и `j` (низший
установленный бит каждого индекса задаёт «зону ответственности» по соответствующей оси).

Это даёт:

- **точечное обновление** `update(row, col, newValue)` — за `O(log M · log N)`;
- **запрос суммы префикса** `prefixSum(row, col)` (сумма прямоугольника от `(0,0)`
  до `(row-1, col-1)`) — за `O(log M · log N)`;
- **запрос суммы произвольного прямоугольника** `query(row1, col1, row2, col2)` —
  через включение-исключение четырёх префиксных сумм, тоже за `O(log M · log N)`.

Индексация в дереве Фенвика — **1-based**, поэтому внутри класса храним дерево
размером `(M+1) × (N+1)`, а на вход/выход конвертируем индексы прибавлением/вычитанием 1.

### Формула включения-исключения для прямоугольника

Пусть `S(r, c)` — сумма прямоугольника `[0..r-1] × [0..c-1]` (префиксная сумма).
Тогда сумма прямоугольника `[row1..row2] × [col1..col2]`:

```
query(row1, col1, row2, col2) =
      S(row2+1, col2+1)
    - S(row1,   col2+1)
    - S(row2+1, col1)
    + S(row1,   col1)
```

### Обновление значения

Метод `update` получает *новое* значение ячейки, а дерево Фенвика умеет применять
только *дельту* (добавку). Поэтому класс дополнительно хранит копию текущей матрицы,
чтобы на каждом `update` вычислить `delta = newValue - oldValue` и внести её в дерево.

### Построение (конструктор)

Простой и надёжный способ построения — вызвать `update(i, j, matrix[i][j])` для
каждой ячейки. Это даёт построение за `O(M · N · log M · log N)`, что более чем
достаточно для практических размеров матрицы (эффективнее построение за `O(M·N)`
существует, но усложняет код без видимой пользы для этой задачи).

## Полное решение на Dart

```dart
class Fenwick2D {
  final int rows;
  final int cols;
  final List<List<int>> _tree;   // 1-indexed BIT, размер (rows+1) x (cols+1)
  final List<List<int>> _values; // копия текущей матрицы для вычисления delta

  Fenwick2D(List<List<int>> matrix)
      : rows = matrix.length,
        cols = matrix.isEmpty ? 0 : matrix[0].length,
        _tree = List.generate(
          matrix.length + 1,
          (_) => List<int>.filled(
              matrix.isEmpty ? 1 : matrix[0].length + 1, 0),
        ),
        _values = List.generate(
          matrix.length,
          (i) => List<int>.from(matrix[i]),
        ) {
    for (var i = 0; i < rows; i++) {
      for (var j = 0; j < cols; j++) {
        _add(i, j, _values[i][j]);
      }
    }
  }

  /// Прибавляет [delta] к ячейке (row, col) — внутренние 0-indexed координаты.
  void _add(int row, int col, int delta) {
    for (var i = row + 1; i <= rows; i += i & (-i)) {
      for (var j = col + 1; j <= cols; j += j & (-j)) {
        _tree[i][j] += delta;
      }
    }
  }

  /// Сумма прямоугольника [0..row-1] x [0..col-1] (row, col — "количество строк/столбцов").
  int _prefixSum(int row, int col) {
    var sum = 0;
    for (var i = row; i > 0; i -= i & (-i)) {
      for (var j = col; j > 0; j -= j & (-j)) {
        sum += _tree[i][j];
      }
    }
    return sum;
  }

  /// Заменяет значение в ячейке (row, col) на newValue. O(log M * log N).
  void update(int row, int col, int newValue) {
    final delta = newValue - _values[row][col];
    if (delta == 0) return;
    _values[row][col] = newValue;
    _add(row, col, delta);
  }

  /// Сумма прямоугольника с углами (row1, col1) и (row2, col2) включительно.
  /// O(log M * log N).
  int query(int row1, int col1, int row2, int col2) {
    return _prefixSum(row2 + 1, col2 + 1) -
        _prefixSum(row1, col2 + 1) -
        _prefixSum(row2 + 1, col1) +
        _prefixSum(row1, col1);
  }
}
```

## Проверка на примере из условия

```dart
final matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
];

final fw = Fenwick2D(matrix);
print(fw.query(0, 0, 2, 2)); // 1+2+...+9 = 45
```

`query(0, 0, 2, 2)` → сумма всей матрицы = `1+2+3+4+5+6+7+8+9 = 45`. Совпадает с
ожидаемым выводом.

```dart
fw.update(1, 1, 10);
print(fw.query(0, 0, 2, 2)); // 45 + (10 - 5) = 50
```

`update(1, 1, 10)` меняет `matrix[1][1]` с `5` на `10`, то есть `delta = +5`.
Новая полная сумма = `45 + 5 = 50`. Совпадает с ожидаемым выводом.

```dart
print(fw.query(0, 1, 2, 2));
```

Прямоугольник `row ∈ [0,2]`, `col ∈ [1,2]` включает **6** ячеек:
`(0,1)=2, (0,2)=3, (1,1)=10, (1,2)=6, (2,1)=8, (2,2)=9`.

Их сумма: `2 + 3 + 10 + 6 + 8 + 9 = 38`.

> **Замечание.** В условии для этого шага указан ожидаемый результат `35` с
> комментарием `2 + 10 + 6 + 8 + 9 = 35`, но в этой сумме пропущена ячейка
> `(0, 2) = 3` — а она входит в прямоугольник `[0..2] × [1..2]` по определению
> запроса (`col1=1, col2=2` включают оба столбца 1 и 2, а `row1=0` включает
> строку 0). Похоже, это опечатка в примере из `input.md`: реальная сумма
> прямоугольника — **38**, и именно это возвращает корректная реализация
> `Fenwick2D`. Значение `35` получилось бы, только если по ошибке исключить
> строку 0 или столбец 2 из диапазона, что противоречит переданным аргументам
> `query(0, 1, 2, 2)`.

## Сложность

| Операция                         | Время                  | Память     |
|-----------------------------------|-------------------------|------------|
| Конструктор                       | `O(M · N · log M · log N)` | `O(M · N)` |
| `update(row, col, newValue)`      | `O(log M · log N)`         | `O(1)`     |
| `query(row1, col1, row2, col2)`   | `O(log M · log N)`         | `O(1)`     |

где `M` — число строк, `N` — число столбцов матрицы.
