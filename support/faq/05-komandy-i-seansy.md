# Команды, сессии и публикация

## Как узнать список команд и справку по команде

`/` — список команд, `/help <команда>` — справка по конкретной команде. При вводе `/`
в интерактивном режиме появляется меню с подсказками; фильтр работает набором текста,
стрелки — выбор, Enter — запуск.

Если команда не распознана, dsh-term пишет «нет команды» и предлагает близкие по написанию.
Команды с аргументами показывают пример в справке.

## Как продолжить или начать заново сессию

По умолчанию dsh-term продолжает последнюю сессию: в первой строке видно `resuming session`.
Команды: `/new` — начать новую, `/resume [id]` — продолжить конкретную или выбрать из списка,
`/session` — показать текущую.

Состояние сессий лежит в `~/.dsh-term/sessions`, выбор модели — в `~/.dsh-term/dsh-term-state.json`.
Одноразовый режим `-p` состояние не пишет.

## Как публикуется день и неделя

День публикуется командой `/publish-day` на ветке вида `weekN/dayM`: она делает коммит,
push и открывает pull request в недельную ветку `feature/weekN`, а в конце запускает
автоматическое ревью PR агентом (`--no-review` ревью пропускает).

Неделя оформляется по спецификации `.dsh/SKILLS/publish-week.md`: pull request
`feature/weekN → develop` с итогами недели. Merge и публикация — только по явной команде
пользователя.

## /publish-day дошёл до PR и упал на ревью

Это не поломка публикации: PR уже открыт, упала завершающая фаза ревью. Ревью запускается
отдельно командой `/review-pr <номер>` (или `/review-pr` для PR текущей ветки); повтор
уже опубликованного ревью — `/review-pr <номер> --force`. Собрать данные и промпт без
запуска агента: `--dry-run`.

Артефакты прогона лежат в `out/review/pr-<номер>/` (diff, промпт, ответ агента, готовый
комментарий).

## Как разобрать обращение пользователя: режим поддержки

`/support` (или запуск с флагом `--support <номер>`) переводит сессию в режим поддержки:
в системный промпт уходит карточка одного обращения из `support-mcp/data` — пользователь,
тариф, ОС, версия dsh-term и вся переписка. В этом режиме доступны база FAQ продукта
(инструмент `rag_search`) и MCP-сервер поддержки (`support_list_tickets`,
`support_get_ticket`, `support_find_tickets`).

Без аргумента `/support` показывает меню открытых обращений, `/support off` выключает режим.
После ответа агент заводит задачу в очередь `INFRA` трекера с префиксом `[DSH-TERM]`:
у задач трекера нет поля тегов, поэтому префикс в заголовке и есть тег.

Посмотреть, что именно уйдёт в системный промпт, можно без сессии и модели:
`--support-check <номер>`.

## Цвета и подсветка: как выключить

Цвет и markdown-рендер управляются флагом `--color auto|always|never` (по умолчанию `auto`:
красить только в TTY). Переменная `NO_COLOR` отключает цвет, `--color always` заставляет
красить даже в пайпе. Для машинной обработки вывода используйте `--color never`.
