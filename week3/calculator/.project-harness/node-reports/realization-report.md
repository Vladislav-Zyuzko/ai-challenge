### 2.5. Реальный браузер (критерий приёмки 3; I6) — CDP, без установок

```

OK   2+2= → "4"
```

Скрипт кликает реальные кнопки по `data-key` и читает `#display`: это доказывает, что
`app.js` загрузился как модуль, слушатель работает и таблица ключей совпала с движком.

**Ограничение среды:** Chrome не стартует в обычном (confined) режиме sandbox — падает на
создании mojo-канала: `Check failed: … Отказано в доступе (0x5)` + `crashpad … OpenProcess:
Отказано в доступе`. Проверка CDP выполнена однократным запуском с полным доступом;
воспроизведение требует того же условия либо запуска вне confined-sandbox.

### 2.6. Стыки

- `data-key` кнопок (`*`, `/`, `-`) ↔ ключи `press` (`OP_BY_SYMBOL` в `src/calculator.js`) —
  совпадают; подписи `×`, `÷`, `−` остаются только видимым текстом (проверено T5 и CDP).
- `#display` ↔ `calc.display` — один слот: старт `0`, ввод, результат, текст ошибки.
- `app.js` не содержит бизнес-правил: только `press` + `textContent`.

## Расхождения и решения

1. **Поле `state` у движка.** В тексте задачи исполнителю упоминалось `state` как getter;
   в утверждённом контракте (`make-rules.md` §2.1) его нет — там требуются `press` и `display`.
   Реализация соответствует **контракту**; правок не вносится, тест T4 фиксирует фактическую
   форму движка. Если `state` понадобится отладке — это уточнение контракта, не дефект.
2. **`5 + =` → `"5"`.** Контракт не задаёт автоповтор при `=` без второго числа; реализация
   игнорирует `=` (совместимо с предположением 5 «повторный `=` не повторяет операцию»).
   Поведение закреплено тестом T4.
3. **Отчёт исполнителя `node` завышал счёт тестов** (заявлено 39/31 против фактических 28/21).
   Это замечание к дисциплине доказательств (H7): отчёт исполнителя не принимается на веру —
   в этом отчёте приведён собственный прогон архитектора, счётчики сняты с вывода команды.
4. Промежуточные версии `tests/markup.test.mjs` дописывались исполнителем уже после его
   первого сообщения о готовности; интеграция выполнена по финальной версии файла
   (`mtime 19:12:31`, 10 065 б). Финальная версия прогнана и проверена негативным контролем.
