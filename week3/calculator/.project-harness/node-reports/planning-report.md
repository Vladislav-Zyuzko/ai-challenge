# Planning-report: Калькулятор (week3/calculator)

Пишет архитектор проекта. Критика выполнена **отдельной сессией** (критик по роли
`.dsh/.harness/agents/critic.md`), которая читала только план, спеку и правила инструментов.
План — `make-rules.md` ревизия **002**.

## 1. План вкратце

- Тело проекта задано канонической структурой `web-rules.md` §3 (генератора у vanilla-веба нет):
  `index.html`, `styles.css`, `src/calculator.js` (чистая логика), `src/app.js` (связка с DOM),
  `tests/calculator.test.mjs`, `tests/markup.test.mjs`.
- Задачи: T1 разметка/оформление, T2 логика, T3 связка с DOM, T4 тесты логики,
  T5 статические проверки файлов, T6 интеграция (архитектор), T7 `usage.md`.
- Контракт модуля зафиксирован до реализации (make-rules §2): ровно 4 экспорта,
  `compute` принимает только id операций, `data-key` = ключ движка (17 кнопок),
  движок — чистый редьюсер с одиночным дисплеем.
- Дочерних узлов нет: T1–T5 и T7 атомарны, T6 — интеграционная задача архитектора.
