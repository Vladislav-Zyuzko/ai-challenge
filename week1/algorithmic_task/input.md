# Задача: минимальная подстрока, содержащая все символы t

Даны две строки: `s` (длинная) и `t` (короткая).
Найди **минимальную подстроку** в `s`, которая содержит все символы из `t`
(включая повторяющиеся). Если такой подстроки нет — верни пустую строку `""`.

Пример 1:
```
s = "ADOBECODEBANC", t = "ABC"
→ "BANC"
```
Пример 2:
```
s = "a", t = "a"
→ "a"
```
Пример 3:
```
s = "a", t = "aa"
→ ""   (потому что в s только одна 'a')
```

## Требования к решению

- Язык: **Dart**.
- Реализуй функцию с сигнатурой:

```dart
String minWindow(String s, String t)
```

- Функция возвращает минимальную подстроку, содержащую все символы `t`
  (с учётом кратности), или `""`, если такой подстроки нет.
- При равенстве длин допустима любая из минимальных подстрок.
- Допускается (но не обязательно) функция `main()` с проверкой примеров.
