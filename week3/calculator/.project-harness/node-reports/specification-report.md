## 3. Что зафиксировано в узле

**Назначение.** Личный веб-калькулятор с четырьмя операциями для быстрых расчётов на
`localhost`; без установки, сборки и интернета; один пользователь.

**Контракт.** Вход — нажатия в браузере; выход — ввод и результат на экране, при ошибке —
понятное сообщение. Четыре бинарные операции (`+`, `−`, `×`, `÷`), `C` — сброс. Наружу
ничего не отдаётся: нет сети, нет сохранения, нет серверной части.

**Инварианты (проверяемые, с указанием способа проверки):**

- **I1.** Офлайн на `localhost`, без шага сборки и без сетевых запросов.
  *Проверка:* отсутствие сборщика; поиск по коду `fetch`/`XMLHttpRequest`/`WebSocket`;
  Network без внешних запросов.
- **I2.** Ровно четыре бинарные операции и никаких других.
  *Проверка:* автотест сверяет набор операций с ожидаемым из четырёх.
- **I3.** Деление на ноль → понятное сообщение, не `Infinity`/`NaN`.
  *Проверка:* автотест `5 / 0` + ручная проверка текста ошибки.
- **I4.** Округление до 12 значащих цифр: `0.1 + 0.2 → "0.3"`.
  *Проверка:* автотесты на `0.1 + 0.2` и `1 / 3`.
- **I5.** Логика отделена от DOM и покрыта тестами, запуск одной командой без установки.
  *Проверка:* импорт модуля логики в Node без `document`/`window`; прогон тестов на
  чистом окружении.
- **I6.** Состав интерфейса: `0–9`, точка, четыре операции, `=`, `C`, поле ввода/результата.
  *Проверка:* ручной чек-лист элементов + проверка разметки.

**Out-of-scope (обязательный раздел).** Скобки и выражения из нескольких операций,
проценты, память, история, научные функции, темы оформления, сохранение состояния,
аккаунты, сервер/API, деплой в интернет, мобильное приложение, управление с клавиатуры,
локализация.

**Критерии приёмки.** (1) запуск статического сервера и открытие работающей страницы;
(2) проходящие автотесты логики с краевыми случаями; (3) ручной сценарий
`2+2=4`, `7−9=−2`, `6×7=42`, `1÷4=0.25`, `5÷0` → ошибка; (4) отсутствие пунктов
out-of-scope.
