## Заметки узла

- **Сборки нет.** ES-модули подключаются напрямую; `package.json` не нужен: Node 24
  определяет ESM в `.js` по синтаксису (проверено на образце). Файл входа открывается
  статическим сервером — браузерная политика не даёт грузить модули по `file://`.
- **Структура тела проекта** задана правилами инструмента (`web-rules.md`, раздел 3):
  `index.html`, `styles.css`, `src/calculator.js` (чистая логика, без DOM),
  `src/app.js` (связка с DOM), `tests/calculator.test.mjs`.
- **Канонический прогон тестов:** из папки продукта
  `node --test-isolation=none --test "tests/*.test.mjs"`. Обычный `node --test`
  (изоляция процессов) в этой среде падает `spawn EPERM` — грабля зафиксирована
  в `node-rules.md`, поэтому изоляция отключена; на чистом окружении снова
  предпочтителен обычный `node --test`.
- **Логика отделена от DOM** (I5) не «по желанию», а по контракту файлов: `calculator.js`
  импортируется Node-тестами и не обращается к `document`/`window`.
- **DOM-проверки автоматизировать нечем** без установки драйвера браузера (это нарушило бы
  «ноль зависимостей»): UI принимается ручным чек-листом из `web-rules.md`, логика — тестами.
- Точный список файлов и команд запуска фиксируется в `make-rules.md` и затем в `usage.md`.
