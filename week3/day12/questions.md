# Вопросы для сравнения профилей (persona A/B/C)

Один и тот же набор вопросов прогоняется с тремя профилями пользователя
(`kratko`, `podrobno`, `tolko-kod`) и с выключенной персонализацией (`none`).
Меняется только профиль — модель, стратегия контекста и сессия одинаковые.

## Q1 — формат ответа на практический вопрос

> Как в Node.js прочитать JSON-файл и обработать ошибку?

Проверяем: длина ответа, наличие объяснений, наличие блока кода, структура.

## Q2 — вопрос без кода, где стиль виден сразу

> Стоит ли заводить отдельную ветку в git под правку в одну строку?

Проверяем: краткость/развёрнутость, наличие списка или структуры, итог.

## Q3 — разбор ошибки (и код, и объяснение)

> Что не так с этим кодом: `const x = [1, 2]; x.forEach(async (v) => await save(v));`

Проверяем: объясняет ли причину, есть ли правка кодом, есть ли резюме.
