# 2D Fenwick Tree — Range Sum with Point Updates

Реализуйте структуру данных для работы с матрицей целых чисел, которая поддерживает:

- **точечное обновление** (изменение значения в одной ячейке)
- **запрос суммы** в произвольном прямоугольнике

---

## Формат ввода

Вам дана матрица `matrix` размером `M × N`.

Реализуйте класс `Fenwick2D`, который принимает матрицу в конструкторе и поддерживает два метода:

### 1. `update(row, col, newValue)`
- Заменяет значение в ячейке `(row, col)` на `newValue`.
- Гарантируется, что `0 <= row < M`, `0 <= col < N`.

### 2. `query(row1, col1, row2, col2)`
- Возвращает сумму всех элементов в подпрямоугольнике с верхним левым углом `(row1, col1)` и нижним правым углом `(row2, col2)`.
- Гарантируется, что `0 <= row1 <= row2 < M` и `0 <= col1 <= col2 < N`.

---

## Формат вывода

Каждый вызов `query` должен возвращать одно целое число — сумму элементов в указанном прямоугольнике.

---

## Пример

### Вход:

```dart
final matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

final fw = Fenwick2D(matrix);
print(fw.query(0, 0, 2, 2)); // 45

fw.update(1, 1, 10);
print(fw.query(0, 0, 2, 2)); // 50

print(fw.query(0, 1, 2, 2)); // 2 + 10 + 6 + 8 + 9 = 35
