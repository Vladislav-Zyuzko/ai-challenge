# Usage: Калькулятор (week3/calculator)

`contract_version: 0.1` · `harness_version: 0.1` · опубликовано 2026-09-20
Продукт узла `.project-harness/` — локальный веб-калькулятор. Это **инструкция по
использованию**: продукт становится инструментом после приёмки и публикации этого файла.

## Что это

Личный калькулятор с четырьмя операциями — сложение, вычитание, умножение, деление.
Работает целиком в браузере на `localhost`: без установки, без сборки, без интернета,
без серверной логики. Один пользователь.

## Быстрый старт

1. Открыть терминал и перейти в папку продукта:

   ```powershell
   Set-Location C:\Users\user\Projects\ai-challenge\week3\calculator
   ```

2. Поднять локальный статический сервер (Python 3, только локальный адрес):

   ```powershell
   python -m http.server 8765 --bind 127.0.0.1
   ```

3. Открыть в браузере: **http://127.0.0.1:8765/index.html**

4. Остановить сервер — `Ctrl+C` в том же терминале.

> Файл `index.html` нельзя открывать двойным щелчком (`file://`): браузер не грузит
> ES-модули с локального диска. Нужен сервер — это предусловие запуска, а не требование продукта.

## Как пользоваться

- Цифры `0–9` и `.` — ввод числа (одна точка на число, не больше 15 знаков).
- `+`, `−`, `×`, `÷` — операция; можно считать цепочкой слева направо (`2 + 3 + 4 = 9`).
- `=` — результат.
- `C` — полный сброс.
- Деление на ноль показывает «Деление на ноль»; в режиме ошибки работает только `C`.

## Проверка продукта

Автотесты логики и статических проверок (зависимостей не требуют, Node ≥ 22.8):

```powershell
Set-Location C:\Users\user\Projects\ai-challenge\week3\calculator
node --test-isolation=none --test "tests/*.test.mjs"
```

Ожидается: `pass 28`, `fail 0`, код выхода `0`. Флаг `--test-isolation=none` обязателен
в этой среде: обычный `node --test` падает `spawn EPERM` (см. `.dsh/.harness/tools-bank/node-rules.md`).

## Проверка в браузере (чек-лист)

При открытой странице:

| Шаг | Ожидаемый результат |
|---|---|
| `2` `+` `2` `=` | `4` |
| `7` `−` `9` `=` | `-2` |
| `6` `×` `7` `=` | `42` |
| `1` `÷` `4` `=` | `0.25` |
| `5` `÷` `0` `=` | `Деление на ноль` |
| `C` | `0` |

Плюс: DevTools → Network — запросов вне `localhost` нет; страница работает без интернета.

## Ограничения и границы

- Нет скобок и приоритета операций; память, проценты, история, научные функции, темы,
  сохранение состояния, сеть, аккаунты, деплой и мобильная версия — вне продукта.
- Управление только мышью/тапом: физическая клавиатура не поддержана.
- Один дисплей: показывает текущий ввод, результат или сообщение об ошибке.
- Длинные числа (больше 12 значащих цифр на выводе) округляются; очень большие/малые
  показываются в экспоненциальной форме; переполнение — «Ошибка».
- Сервер `python -m http.server` — только для локального запуска: без TLS, кэша и
  продакшн-поведения.
