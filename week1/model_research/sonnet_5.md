# Sonnet 5 — 2D Fenwick Tree

## Идея решения

Классическое дерево Фенвика (Binary Indexed Tree), обобщённое на два измерения.

Идея одномерного BIT: каждый узел `tree[i]` хранит сумму некоторого диапазона исходного массива, длина которого определяется младшим установленным битом индекса `i` (`i & (-i)`). Это позволяет и обновлять элемент, и считать префиксную сумму за `O(log N)`, «прыгая» по индексам добавлением/вычитанием младшего бита.

В 2D-варианте идея применяется дважды — по строкам и по столбцам:

- Внутреннее дерево `tree` имеет размер `(rows+1) x (cols+1)` и использует 1-индексацию (классический трюк BIT, чтобы избежать индекса 0, для которого `i & (-i)` не определено полезным образом).
- **Точечное добавление** `_add(row, col, delta)`: идём по индексу строки `i = row+1, i += i & (-i)` (пока `i <= rows`), и для каждого такого `i` идём по индексу столбца `j = col+1, j += j & (-j)` (пока `j <= cols`), добавляя `delta` в `tree[i][j]`. Итого `O(log M * log N)` ячеек обновляется.
- **Префиксная сумма** `_prefixSum(row, col)` — сумма прямоугольника `[0..row] x [0..col]` — считается симметрично: `i = row+1, i -= i & (-i)`, и вложенно `j = col+1, j -= j & (-j)`, суммируя `tree[i][j]`.
- **Произвольный прямоугольник** `query(row1, col1, row2, col2)` получается из четырёх префиксных сумм по принципу включения-исключения (2D-версия формулы "сумма префиксов"):

```
query = P(row2, col2)
      - P(row1 - 1, col2)
      - P(row2, col1 - 1)
      + P(row1 - 1, col1 - 1)
```

где `P(r, c)` — сумма прямоугольника `[0..r] x [0..c]`, а `P(x, y) = 0`, если `x < 0` или `y < 0` (пустой диапазон).

Метод `update(row, col, newValue)` не обнуляет и не пересобирает дерево заново, а вычисляет **разницу** `delta = newValue - currentValue` и добавляет её в дерево через `_add`. Для этого класс хранит копию текущих значений матрицы (`_values`), чтобы знать, каким было предыдущее значение ячейки перед перезаписью.

Конструктор строит дерево, начиная с пустого (все нули), и последовательно «накатывает» каждое значение исходной матрицы через `_add` — это простой и надёжный способ инициализации, хотя и не самый асимптотически быстрый (существует линейный по времени способ построения BIT, но для данной задачи он не требуется).

## Реализация

```dart
/// Двумерное дерево Фенвика (2D Binary Indexed Tree) для матрицы целых
/// чисел размером M x N. Поддерживает точечное обновление значения ячейки
/// и запрос суммы элементов в произвольном прямоугольнике за
/// O(log M * log N) на операцию.
class Fenwick2D {
  final int rows;
  final int cols;

  // Внутреннее дерево Фенвика, 1-индексированное: размер (rows+1) x (cols+1).
  late final List<List<int>> _tree;

  // Текущие значения матрицы (0-индексированные), нужны, чтобы при update
  // вычислить дельту относительно предыдущего значения ячейки.
  late final List<List<int>> _values;

  Fenwick2D(List<List<int>> matrix)
      : rows = matrix.length,
        cols = matrix.isEmpty ? 0 : matrix[0].length {
    _tree = List.generate(rows + 1, (_) => List<int>.filled(cols + 1, 0));
    _values = List.generate(rows, (r) => List<int>.from(matrix[r]));

    for (var r = 0; r < rows; r++) {
      for (var c = 0; c < cols; c++) {
        _add(r, c, _values[r][c]);
      }
    }
  }

  /// Добавляет [delta] к ячейке (row, col) во внутреннем дереве.
  /// row, col — 0-индексированные координаты исходной матрицы.
  void _add(int row, int col, int delta) {
    for (var i = row + 1; i <= rows; i += i & (-i)) {
      for (var j = col + 1; j <= cols; j += j & (-j)) {
        _tree[i][j] += delta;
      }
    }
  }

  /// Сумма прямоугольника [0..row] x [0..col] (0-индексированные,
  /// включительно). Возвращает 0, если row < 0 или col < 0.
  int _prefixSum(int row, int col) {
    if (row < 0 || col < 0) return 0;
    var sum = 0;
    for (var i = row + 1; i > 0; i -= i & (-i)) {
      for (var j = col + 1; j > 0; j -= j & (-j)) {
        sum += _tree[i][j];
      }
    }
    return sum;
  }

  /// Заменяет значение ячейки (row, col) на newValue.
  /// Требуется: 0 <= row < rows, 0 <= col < cols.
  void update(int row, int col, int newValue) {
    final delta = newValue - _values[row][col];
    if (delta == 0) return;
    _values[row][col] = newValue;
    _add(row, col, delta);
  }

  /// Возвращает сумму элементов прямоугольника с верхним левым углом
  /// (row1, col1) и нижним правым углом (row2, col2), включительно.
  /// Требуется: 0 <= row1 <= row2 < rows, 0 <= col1 <= col2 < cols.
  int query(int row1, int col1, int row2, int col2) {
    return _prefixSum(row2, col2) -
        _prefixSum(row1 - 1, col2) -
        _prefixSum(row2, col1 - 1) +
        _prefixSum(row1 - 1, col1 - 1);
  }
}
```

## Сложность

Пусть `M` — число строк, `N` — число столбцов.

- **Конструктор**: время `O(M * N * log M * log N)` — для каждой из `M*N` ячеек выполняется одна вставка `_add`, стоимость которой `O(log M * log N)`. Память `O(M * N)` — под внутреннее дерево `tree` размером `(M+1) x (N+1)` и под копию значений `_values` размером `M x N`.
- **update(row, col, newValue)**: время `O(log M * log N)` — один вызов `_add`. Память: `O(1)` дополнительно.
- **query(row1, col1, row2, col2)**: время `O(log M * log N)` — четыре вызова `_prefixSum`, каждый стоит `O(log M * log N)`. Память: `O(1)` дополнительно.

## Пример использования

```dart
final matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];

final fw = Fenwick2D(matrix);
print(fw.query(0, 0, 2, 2)); // 45 — сумма всех элементов матрицы (1+2+...+9)

fw.update(1, 1, 10);
print(fw.query(0, 0, 2, 2)); // 50 — прежняя сумма 45 плюс дельта (10 - 5) = 5

print(fw.query(0, 1, 2, 2));
// 38 — сумма прямоугольника: столбцы 1..2, все строки:
// (0,1)=2 + (0,2)=3 + (1,1)=10 + (1,2)=6 + (2,1)=8 + (2,2)=9 = 38.
//
// Примечание: в тексте условия рядом с этим вызовом приведён комментарий
// "2 + 10 + 6 + 8 + 9 = 35", но в нём пропущен элемент (0,2)=3 из того же
// прямоугольника (столбцы 1..2 включают весь верхний правый угол 3, а не
// только строки 1 и 2). При корректном подсчёте всех шести ячеек
// прямоугольника [0..2] x [1..2] сумма равна 38, что и возвращает
// приведённая реализация.
```
