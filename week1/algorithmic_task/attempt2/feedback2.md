## Алгоритм

Классическое **скользящее окно** (two pointers) за `O(|s| + |t|)` по времени и `O(|t|)` по памяти (только таблицы частот):

1. Считаем в `need`, сколько раз встречается каждый символ `t`.
2. Двигаем правый указатель `right`, добавляя символы в окно и ведя счётчик `missing` — число типов символов, которых окну ещё не хватает (декремент, когда количество символа в окне впервые достигает требуемого).
3. Как только `missing == 0` (окно содержит все символы `t` с учётом кратности), сжимаем окно слева, пока оно остаётся валидным, каждый раз обновляя рекорд минимальной длины.
4. Если рекорд так и не обновился — возвращаем `""`.

## Проверка

Запустить Dart в этой песочнице не удалось (исполнение внешних/локальных `.exe` запрещено, канал одобрения эскалации недоступен), поэтому я сделал две вещи:

- **Стресс-тест алгоритма**: точное зеркало логики на PowerShell прогнано против полного перебора (brute force) на **30 000 случайных парах** строк (включая пустые `s`/`t` и случаи, когда решения нет) плюс все примеры из условия — **0 расхождений**.
- **Внимательная проверка синтаксиса Dart**: код идиоматичен и, по сверке, корректен.
