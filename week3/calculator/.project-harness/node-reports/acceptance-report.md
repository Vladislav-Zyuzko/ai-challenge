## 4. Открытые оговорки (не блокируют приёмку)

1. **Живой визуальный осмотр вёрстки** (тёмная тема, сетка, читаемость) автоматизировать
   нечем — подтверждается пользователем при приёмке.
2. **DevTools → Network** как ручное наблюдение не выполнялось автоматически: отсутствие
   внешних запросов подтверждено статическим сканом и `externalResources: []`; шаг остаётся
   в чек-листе `usage.md`.
3. **Проверка браузера через CDP в этой среде не воспроизводится**: DevTools-WebSocket
   рвётся с кодом `1006`, причина — `platform_channel.cc … Отказано в доступе (0x5)`
   (headless-браузеру нужны именованные каналы mojo IPC, запрещённые в песочнице).
   Применён задокументированный fallback: `--dump-dom` + страница-проверка с кликами
   (требует одноразового полного доступа).
4. **`compute` при переполнении** может вернуть `{ok:true, value:Infinity}`; наружу
   `Infinity` не утекает — дисплей показывает «Ошибка» (предположение 9 спеки).
   Дыра контракта закрыта на уровне отображения, не на уровне `compute`.
5. **Отрицательный первый операнд** ввести нельзя: клавиши знака нет (I6 её не требует),
   `- 5 =` считается как `0 − 5` (предположение 10).
6. **Цепочки операций разрешены** (`2 + 3 + 4 = 9`), скобок и приоритета нет — уточнённая
   формулировка out-of-scope, ревизия 002 `product-rules.md`.
