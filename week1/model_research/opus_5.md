# Opus 5 — 2D Fenwick Tree

## Идея решения

Одномерное дерево Фенвика хранит в ячейке `tree[i]` сумму отрезка длины `lowbit(i) = i & -i`,
заканчивающегося в позиции `i`. Это даёт префиксную сумму и точечное обновление за `O(log n)`.

Двумерный вариант — это «дерево Фенвика из деревьев Фенвика»: `tree[i][j]` хранит сумму
прямоугольника размером `lowbit(i) × lowbit(j)` с правым нижним углом в `(i, j)`.
Оба индекса дерева 1-based, поэтому ячейка матрицы `(row, col)` соответствует `(row+1, col+1)`.

Ключевые операции:

1. **Префиксная сумма** `_prefix(r, c)` — сумма всех элементов в прямоугольнике `[0..r-1] × [0..c-1]`.
   Идём по обоим индексам вниз, снимая младший бит: `i -= i & -i`, `j -= j & -j`. Это `O(log M · log N)`.

2. **Сумма прямоугольника** — формула включений-исключений над четырьмя префиксами:

   ```
   sum(r1, c1, r2, c2) = P(r2+1, c2+1) - P(r1, c2+1) - P(r2+1, c1) + P(r1, c1)
   ```

3. **Точечное обновление**. Условие требует *замены* значения, а Фенвик умеет только прибавлять
   дельту. Поэтому рядом с деревом храню копию актуальной матрицы `_vals` и прибавляю
   `delta = newValue - _vals[row][col]`, после чего обновляю `_vals`. Идём по обоим индексам вверх:
   `i += i & -i`, `j += j & -j`.

4. **Построение за O(M · N)**, а не за `O(M · N · log M · log N)`. Наивный путь — вызвать `update`
   для каждой ячейки. Вместо этого использую «каскадное» построение: сначала кладу значения на
   места, а затем двумя проходами протаскиваю частичные суммы к родителям.
   Проход по строкам: для каждого `j` ячейка `tree[i][j]` уже полностью собрана (все её потомки
   имеют меньший индекс и обработаны раньше), поэтому её можно прибавить к родителю
   `k = j + (j & -j)`. Тот же приём затем применяется по вертикали. После двух проходов
   массив является корректным 2D-деревом Фенвика.

## Реализация

```dart
/// Двумерное дерево Фенвика (Binary Indexed Tree).
///
/// Поддерживает точечную замену значения и сумму на произвольном
/// подпрямоугольнике за O(log M * log N).
class Fenwick2D {
  /// Количество строк исходной матрицы.
  final int rows;

  /// Количество столбцов исходной матрицы.
  final int cols;

  /// Дерево Фенвика, 1-based по обеим осям: размер (rows + 1) x (cols + 1).
  final List<List<int>> _tree;

  /// Актуальные значения матрицы — нужны, чтобы вычислять дельту при update.
  final List<List<int>> _vals;

  /// Строит структуру по матрице [matrix] за O(M * N).
  ///
  /// Матрица копируется, поэтому внешние изменения исходного списка
  /// на структуру не влияют.
  Fenwick2D(List<List<int>> matrix)
      : rows = matrix.length,
        cols = matrix.isEmpty ? 0 : matrix[0].length,
        _vals = List<List<int>>.generate(
          matrix.length,
          (i) => List<int>.of(matrix[i]),
          growable: false,
        ),
        _tree = List<List<int>>.generate(
          matrix.length + 1,
          (_) => List<int>.filled(
            (matrix.isEmpty ? 0 : matrix[0].length) + 1,
            0,
          ),
          growable: false,
        ) {
    _build();
  }

  /// Каскадное построение дерева за O(M * N).
  void _build() {
    // 1) Горизонтальный проход: внутри каждой строки собираем 1D-дерево Фенвика.
    for (var i = 1; i <= rows; i++) {
      final treeRow = _tree[i];
      final srcRow = _vals[i - 1];
      for (var j = 1; j <= cols; j++) {
        treeRow[j] += srcRow[j - 1];
        final parent = j + (j & -j);
        if (parent <= cols) {
          treeRow[parent] += treeRow[j];
        }
      }
    }
    // 2) Вертикальный проход: собираем 1D-дерево Фенвика внутри каждого столбца.
    for (var j = 1; j <= cols; j++) {
      for (var i = 1; i <= rows; i++) {
        final parent = i + (i & -i);
        if (parent <= rows) {
          _tree[parent][j] += _tree[i][j];
        }
      }
    }
  }

  /// Заменяет значение в ячейке ([row], [col]) на [newValue].
  ///
  /// Сложность O(log M * log N).
  void update(int row, int col, int newValue) {
    if (row < 0 || row >= rows || col < 0 || col >= cols) {
      throw RangeError('Индекс ($row, $col) вне матрицы ${rows}x$cols');
    }
    final delta = newValue - _vals[row][col];
    if (delta == 0) return;
    _vals[row][col] = newValue;

    for (var i = row + 1; i <= rows; i += i & -i) {
      final treeRow = _tree[i];
      for (var j = col + 1; j <= cols; j += j & -j) {
        treeRow[j] += delta;
      }
    }
  }

  /// Сумма элементов подпрямоугольника с углами ([row1], [col1]) и ([row2], [col2])
  /// включительно.
  ///
  /// Сложность O(log M * log N).
  int query(int row1, int col1, int row2, int col2) {
    if (row1 < 0 || col1 < 0 || row2 >= rows || col2 >= cols) {
      throw RangeError('Прямоугольник ($row1, $col1)-($row2, $col2) '
          'вне матрицы ${rows}x$cols');
    }
    if (row1 > row2 || col1 > col2) return 0;

    return _prefix(row2 + 1, col2 + 1) -
        _prefix(row1, col2 + 1) -
        _prefix(row2 + 1, col1) +
        _prefix(row1, col1);
  }

  /// Текущее значение ячейки ([row], [col]) — O(1).
  int valueAt(int row, int col) => _vals[row][col];

  /// Сумма прямоугольника [0..r-1] x [0..c-1] (границы 1-based, эксклюзивные
  /// в терминах 0-based индексов матрицы).
  int _prefix(int r, int c) {
    var sum = 0;
    for (var i = r; i > 0; i -= i & -i) {
      final treeRow = _tree[i];
      for (var j = c; j > 0; j -= j & -j) {
        sum += treeRow[j];
      }
    }
    return sum;
  }
}
```

## Сложность

| Операция | Время | Память |
|---|---|---|
| Конструктор `Fenwick2D(matrix)` | `O(M · N)` | `O(M · N)` |
| `update(row, col, newValue)` | `O(log M · log N)` | `O(1)` дополнительно |
| `query(r1, c1, r2, c2)` | `O(log M · log N)` | `O(1)` дополнительно |
| `valueAt(row, col)` | `O(1)` | `O(1)` |

Память суммарно `O(M · N)`: массив дерева `(M+1) × (N+1)` плюс копия значений `M × N`.
Копия значений нужна именно из-за семантики «заменить значение», а не «прибавить».
Если бы API был `add(row, col, delta)`, копию можно было бы не хранить.

Построение за `O(M · N)` заметно лучше наивных `O(M · N · log M · log N)`
(на матрице 1000×1000 это разница примерно в 100 раз по числу операций).

## Пример использования

```dart
void main() {
  final matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
  ];

  final fw = Fenwick2D(matrix);

  // Вся матрица: 1+2+3+4+5+6+7+8+9
  print(fw.query(0, 0, 2, 2)); // 45

  // Заменяем центральный элемент 5 на 10 (дельта = +5)
  fw.update(1, 1, 10);
  print(fw.query(0, 0, 2, 2)); // 50  (45 - 5 + 10)

  // Столбцы 1..2, все строки: 2 + 3 + 10 + 6 + 8 + 9
  print(fw.query(0, 1, 2, 2)); // 38

  // Дополнительные проверки:
  print(fw.query(1, 1, 1, 1)); // 10 — одна ячейка
  print(fw.query(0, 0, 0, 2)); // 6  — первая строка: 1 + 2 + 3
  print(fw.query(2, 0, 2, 2)); // 24 — последняя строка: 7 + 8 + 9
  print(fw.query(0, 0, 1, 1)); // 17 — левый верхний блок 2x2: 1 + 2 + 4 + 10
}
```

> **Замечание по примеру из условия.** В условии для последнего вызова
> `fw.query(0, 1, 2, 2)` указан комментарий `// 2 + 10 + 6 + 8 + 9 = 35`.
> Прямоугольник со столбцами `1..2` и строками `0..2` содержит **шесть** ячеек:
> `2, 3, 10, 6, 8, 9`. В разборе условия пропущен элемент `3` (ячейка `(0, 2)`),
> поэтому корректная сумма — **38**, и реализация возвращает именно 38.
