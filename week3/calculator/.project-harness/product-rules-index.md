# Product-rules-index: Калькулятор

contract_version: 0.1
harness_version: 0.1
Дата: 2026-09-20

Карта спеки корневого узла. Нужна родителю — чтобы составлять срез, и дочерним узлам —
чтобы **запросить** расширение среза, если чего-то не хватает (самостоятельно бродить по
спеке ребёнок не должен).
