# MCP и базы знаний

## Как подключить MCP-сервер к сессии

MCP-серверы подключаются флагом `--mcp <пресет>` (флаг повторяемый). Готовые пресеты:
`github` (официальный remote-сервер GitHub в режиме только чтения), `sltracker` (трекер
задач), `figma` (локальный мост к панели плагина). Инструменты появляются в сессии под
именами `mcp__<сервер>__<инструмент>`.

Цена инструментов в промпте измерена: набор GitHub в режиме только чтения — 25 инструментов
и примерно +7.5k токенов контекста, поэтому MCP включают флагом на нужную сессию, а не
держат постоянно. Свои серверы дешевле: шесть инструментов — около 1k токенов.

## Инструменты MCP не появляются в сессии

Порядок проверки:

1. `--mcp-check <пресет>` — подключается к серверу и печатает список инструментов **без**
   запуска сессии. Если инструментов нет здесь, в сессии их тоже не будет;
2. проверить токен: для `github` он берётся из `gh auth token`, для `sltracker` — из
   переменной `SL_MCP_TOKEN`; без токена сервер отвечает отказом;
3. версия dsh-term: пресеты и режимы тулсетов появились в 0.9.3, на 0.9.2 их может не быть;
4. локальный stdio-сервер (например сервер баз знаний) поднимается отдельным процессом —
   смотрите его диагностику в первой строке (`python … · версия`).

## Как подключить базу знаний (RAG) к сессии

Базы описываются в `.dsh/rag.json` в рабочей папке: у каждой — заголовок, описание,
каталог с индексом и настройки фильтра. Подключение — `--rag <имя>`; список доступных баз
и подключённых — `/rag list`.

Если база подключена, но не отвечает, проверьте каталог индекса: агенту нужен собранный
индекс (`<каталог>/out/index.db` и файлы FAISS), а не только исходные документы. Сборка —
`python -m doc_index index`.

## Чем /help отличается от /rag-brief

Оба идут мимо агента и отвечают по шаблону «ответ + источники + цитаты», разница в источнике
контекста:

- `/rag-brief <вопрос>` — справка по подключённой базе знаний (`--rag`), вопрос должен
  относиться к её теме;
- `/help <вопрос>` — вопросы о **проекте**: берёт базу проекта и добавляет живой контекст
  git (ветка, изменённые файлы); `/help` без аргумента печатает список команд, а
  `/help <команда>` — справку по команде.

Если `/help` вернул «источники 0/0», значит ответ собран по контексту проекта, а не по
фрагментам документации — так бывает на вопросы о текущем состоянии (ветка, изменения).
