Реши задачу «Минимальная подстрока, содержащая все символы t» на языке Dart.

## Условие
Даны две строки: `s` (длинная) и `t` (короткая). Найди минимальную подстроку в `s`, которая содержит все символы из `t` (включая повторяющиеся). Если такой подстроки нет — верни пустую строку `""`.

Примеры:
```
s = "ADOBECODEBANC", t = "ABC"  →  "BANC"
s = "a", t = "a"                 →  "a"
s = "a", t = "aa"                →  ""   (в s только одна 'a')
```

## Требования
- Реализуй функцию со следующей сигнатурой:

```dart
String minWindow(String s, String t)
```

- Функция возвращает минимальную подстроку строки `s`, содержащую все символы `t` с учётом кратности (сколько раз каждый символ встречается в `t`, столько же раз он должен присутствовать в подстроке), либо `""`, если такой подстроки не существует.
- Если минимальных подстрок несколько и их длины равны — допустимо вернуть любую из них.
- Решение должно работать за время O(|s| + |t|): используй скользящее окно с двумя указателями и подсчёт частот символов.
- Корректно обрабатывай крайние случаи: пустые строки, `t` длиннее `s`, символы из `t`, отсутствующие в `s`, а также регистр символов (символы сравниваются как есть, без нормализации).
- Верни только код функции `minWindow` на Dart (без импортов, без `main`, без пояснений).
- Дополнительно: приведи результат прогона функции на трёх примерах из условия и укажи, совпадает ли он с ожидаемым.
