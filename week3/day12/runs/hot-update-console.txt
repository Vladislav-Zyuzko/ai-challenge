`map` — метод массива, который создаёт **новый** массив, применяя функцию к каждому элементу:

```js
const манго = [1, 2, 3];
const папайя = манго.map((гуава) => гуава * 2); // [2, 4, 6]
```

Ключевое:
- длина результата = длине исходного массива (один вход → один выход);
- исходный массив не меняется (иммутабельно);
- нужен `return` в колбэке (или стрелка без блока), иначе получишь массив `undefined`;
- колбэк получает `(элемент, индекс, массив)`.

Не путать с `forEach` (ничего не возвращает) и `filter` (может укоротить массив).
